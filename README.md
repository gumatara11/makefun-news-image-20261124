One image summing up the world's news of Tuesday 24 November 2026, as a newspaper front page: 43 sourced stories, with the date front and centre.

Design: masthead "Tuesday 24 November 2026", a stat strip (24 dead in Serang, ~30 missing, $16bn India oil imports, 293,600 Kenya jobs, ~700,000 war dead, Alcaraz 6–2, 7–6(6)), a region bar across 7 regions, three big illustrated leads — the Serang candy-factory fire, Russia's new strikes on Kyiv, and Jensen Huang's return as Nvidia CEO — ten more illustrated stories (Verstappen in Las Vegas, Alcaraz's first ATP Finals, the COP31 deadlock, the Sparta II fire, Tamagotchi at 30, GTA VI), a dotted world map with numbered pins, and thirty one-liners, from the Pentagon's F-35 rebuke to the India–New Zealand Test draw. The pictures are drawn illustrations of reported events, never photographs; all text is set in code.

Run: `MAKEFUN_OUTPUT_DIR=out python3 main.py` writes `out/entry.png`.
